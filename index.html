Algorithm Specification

The step-by-step procedure implemented by the stack word reversal algorithm.

1

Start

Begin the execution of the program and initialize system memory parameters.

2

Read Input Word

Accept the target string or word from standard user input and determine length n.

3

Initialize Empty Stack

Create a character array stack and set the stack pointer top = -1.

4

Push Characters

Iterate from index 0 to n-1 and call push(str[i]) for every character.

5

Pop All Characters

While isEmpty() is false, extract characters one by one via pop().

6

Append Characters

Place each successively popped character into consecutive slots of the reversed word string.

7

8

Stop

Theoretical Analysis

Complexity & Data Structure Analysis

Rigorous asymptotic performance evaluation and structural characteristics.

Time Complexity
O(n)

Pushing n elements takes O(n) and popping n elements takes O(n). Total operations: 2n ∈ O(n).

Space Complexity
O(n)

Auxiliary memory allocated for the stack array storing n individual characters of the input string.

Data Structure Used
Stack

Sequential linear data structure adhering strictly to single-ended insertion and deletion via top.

Core Principle
LIFO

Last In, First Out: The element most recently placed onto the stack is invariably the first element removed.

Why Stack is the Optimal Choice for Word Reversal

  • Natural Reversal: The LIFO property automatically reverses chronological order without requiring two-pointer pointer swapping or extra arithmetic.
  • Constant Time Operations: Both push() and pop() execute strictly in O(1) time complexity.
  • Deterministic Footprint: Array-based implementation eliminates memory pointer overhead of linked nodes (saving 8 bytes per char).

Boundary & Error Handling Conditions

  • Stack Overflow: Occurs if top == MAX - 1. Prevented by checking capacity in isFull() before attempting any push().
  • Stack Underflow: Occurs when top == -1 and pop() is invoked. Safely caught by returning null terminator '\0'.
  • Empty Input Guard: Code sanitizes inputs and handles empty strings gracefully without segmentation faults.
